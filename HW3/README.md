# SmartDeclutter 🧹 智能檔案整理與清理工具

你的「下載」資料夾或電腦桌面總是一團亂嗎？常常因為忘記檔案放在哪，而不小心下載或複製了一堆完全相同的檔案，白白浪費寶貴的硬碟空間嗎？

**SmartDeclutter** 是一個使用純 Python 打造的輕量級命令列工具。它能一鍵幫您將混亂的檔案自動分類，並透過安全的雜湊演算法精準揪出重複檔案，讓您的硬碟瞬間煥然一新！

---

## ✨ 核心特色與價值

- 🚀 **一鍵自動分類**：依據檔案類型（圖片、文件、影音、壓縮檔、程式碼），自動建立對應的資料夾並將檔案歸位。
- 👯 **精準揪出重複檔案**：採用 **SHA-256 雜湊演算法** 比對檔案的「真實內容」而非「檔名」，100% 精準找出重複檔案。
- 🛡️ **安全第一的設計**：偵測到的重複檔案**不會被直接刪除**，而是被安全地移至 `Duplicates_Trash (重複檔案)` 資料夾，讓您做最後確認。
- ⚡ **零依賴、隨插即用**：完全使用 Python 內建模組開發，**不需要 `pip install` 任何套件**，在任何有 Python 的環境皆可無痛執行。

---

## 📥 安裝與執行

本專案無需安裝任何第三方依賴，只要您的電腦有安裝 Python 3.6 以上版本即可運行。

1. **下載專案**：
   將 `declutter.py` 下載到您的電腦中。
   ```bash
   git clone https://github.com/您的帳號/SmartDeclutter.git
   cd SmartDeclutter
   ```

2. **執行程式**：
   打開終端機，輸入以下指令並接上您想整理的資料夾路徑。
   ```bash
   python declutter.py /你的路徑/想整理的資料夾
   ```
   *(💡 提示：如果不加上路徑，直接執行 `python declutter.py`，程式將預設整理您「當前所在的目錄」。)*

## 📂 整理效果對照

**整理前 (Before)：**
```text
混亂的資料夾/
├── 報告v1.pdf
├── 報告v1_copy.pdf  (內容與報告v1相同)

├── IMG_9921.jpg   (內容與渡假照片相同)
├── 專案原始碼.zip

```

**整理後 (After)：**
```text
乾淨的資料夾/
├── Documents (文件)/
│   └── 報告v1.pdf
├── Images (圖片)/
│   └── 渡假照片.jpg
├── Archives (壓縮檔)/
│   └── 專案原始碼.zip
├── Code (程式碼)/
│   └── index.html
└── Duplicates_Trash (重複檔案)/
    ├── 報告v1_copy_143022.pdf  <-- 揪出的重複檔案
    └── IMG_9921_143022.jpg     <-- 揪出的重複檔案
```

## 🛠️ 自訂分類規則

如果您想增加新的檔案格式或更改資料夾名稱，只需打開 `declutter.py`，修改頂部的 `FILE_CATEGORIES` 字典即可：

```python
FILE_CATEGORIES = {
    'Images (圖片)': ['.jpg', '.jpeg', '.png', '.gif', '.webp'],
    'Documents (文件)': ['.pdf', '.doc', '.docx', '.txt', '.xlsx', '.csv'],
    'Media (影音)': ['.mp4', '.mp3', '.mov'],
    # 您可以在這裡自由新增您的專屬分類！
}
```

---

## ⚠️ 注意事項

- 執行前，請確保沒有其他程式正在開啟或編輯目標資料夾中的檔案。
- 程式會將重複的檔案集中到 `Duplicates_Trash (重複檔案)` 資料夾。**請您親自確認該資料夾內的檔案無誤後，再手動將其刪除以釋放硬碟空間。**
