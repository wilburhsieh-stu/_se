# 🎓 大學校務系統 Web 版原型 (School System Web Prototype)

這是一個使用 Python、Flask 與 SQLite 實作的輕量級「大學校務系統」原型。專案展示了核心的「選課系統」商業邏輯，包含學生註冊、課程開設以及選課檢核（名額限制與重複選課防護），並提供了一個簡單直覺的網頁操作介面。

## ✨ 系統功能

*   👤 **學生管理**：新增學生基本資料（學號、姓名、科系）。
*   📚 **課程管理**：開設新課程，設定學分數與**修課人數上限**。
*   ✅ **選課引擎**：
    *   學生輸入學號與課程代碼進行選課。
    *   **自動檢核**：防止重複選修同一門課。
    *   **滿班防護**：即時檢查課程已選人數，額滿自動阻擋。
*   💾 **持久化儲存**：使用 SQLite 實體資料庫，重啟系統資料不遺失。
*   🌐 **Web 介面**：單一頁面即時操作與查看結果，並具備操作成功/失敗的提示訊息。

## 📦 環境安裝與執行

本專案只需依賴 Python 內建庫與輕量級 Web 框架 `Flask`。

### 1. 安裝 Flask
請確保您的環境已經安裝 Python 3，並執行以下指令安裝 Flask：
```bash
pip install Flask
```

### 2. 執行系統
將主程式儲存為 `app.py`，並在終端機執行：
```bash
python app.py
```

### 3. 開啟網頁
伺服器啟動後，打開您的瀏覽器並進入以下網址即可開始操作：
👉 **http://127.0.0.1:5000**

## 📂 專案結構

為了方便測試與部署，本原型採用極簡結構：

```text
nqu_system_project/
├── app.py             # 包含後端邏輯、資料庫操作與前端 HTML 模板
```

## 💡 使用流程範例

1.  **建立測試資料**：
    *   在左側「新增學生」區塊，新增一位學生（例如：學號 `11201`，姓名 `王小明`）。
    *   在中間「新增課程」區塊，新增一門課程（例如：代碼 `CS101`，名稱 `程式設計`，人數上限設為 `1`）。
2.  **進行選課**：
    *   在右側「學生選課」區塊，輸入剛才的學號 `11201` 與課號 `CS101`，點擊送出。
    *   頁面頂部會顯示綠色的「選課成功！」提示，且中間的課程列表會更新為 `(1/1)`。
3.  **測試邏輯阻擋**：
    *   **重複選課**：再次用同一位學生選 `CS101`，系統會跳出紅色警告「你已經選過這門課了！」。
    *   **滿班阻擋**：新增第二位學生（學號 `11202`）並嘗試選修 `CS101`，系統會跳出紅色警告「課程已額滿！」。
