# NMIXX Discography 歷年作品集 🎵

這是一個專為 K-pop 女團 **NMIXX** 打造的靜態作品展示網站。完整收錄了從 2022 年出道至 2026 年的歷年專輯與詳細曲目。

網站的視覺設計靈感汲取自《Strange Muse》等專輯的空靈與夢幻概念，採用了動態漸層背景結合玻璃擬物化 (Glassmorphism) 風格，為 NSWER 們提供最流暢、美觀的瀏覽體驗。

## ✨ 專案特色 (Features)

- 💿 **完整歷年作品**：精確收錄包含《Heavy Serenade》、《Blue Valentine》與《Strange Muse》等最新專輯的完整曲目。
- 🎨 **空靈系玻璃 UI**：半透明毛玻璃卡片設計搭配紫、粉、藍色調的動態漸層背景。
- 📱 **響應式設計**：完美支援手機、平板與桌上型電腦的跨螢幕瀏覽。
- ⚡ **極致效能**：純 HTML / CSS 打造，無多餘套件依賴，搭配 Cloudflare Pages 全球 CDN，實現毫秒級載入。

## 🛠️ 技術堆疊 (Tech Stack)

- **前端**：HTML5, CSS3 (純手寫樣式、CSS 動畫)
- **部署與託管**：[Cloudflare Pages](https://pages.cloudflare.com/)
- **開發工具**：Wrangler CLI
